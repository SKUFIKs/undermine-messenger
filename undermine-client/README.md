# UnderMine Web Client (React + TypeScript)

Современный веб-клиент для криптографического мессенджера UnderMine.

## Возможности

- **Авторизация и регистрация** — через HTTP API сервера (`/api/v1/auth/register`, `/api/v1/auth/login`)
- **Обмен сообщениями в реальном времени** — через WebSocket (`/ws`)
- **Сквозное шифрование (E2EE)** — Curve25519 (ECDH) + ChaCha20-Poly1305 AEAD
- **Офлайн-доставка сообщений** — автоматическое получение отложенных пакетов
- **Поиск контактов** — поиск по имени пользователя в каталоге публичных ключей
- **Тестовый сплит-режим** — одновременная симуляция двух клиентов в одном окне для тестирования шифрования

## Конфигурация

```env
SERVER_URL=http://localhost:8080
```

## Запуск

```bash
npm install
npm run dev
```
